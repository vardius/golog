## What you get

<CardGrid>
	<Card title="Lines for people" icon="document">
		The time, a level that lines up, the message as it is, then `key=value`. Values are quoted only when they need
		to be, and a record is always one line.
	</Card>
	<Card title="Colour for terminals" icon="star">
		Levels in colour, the time and keys dimmed, errors in red. One option, off for files and pipes.
	</Card>
	<Card title="Standard slog" icon="approve-check">
		A `slog.Handler`: log with `*slog.Logger`, set levels with `slog.LevelVar`, rewrite with `ReplaceAttr`.
		It passes the standard library's `testing/slogtest`.
	</Card>
	<Card title="No allocations" icon="rocket">
		Values go straight into a pooled buffer, `With` attributes are formatted once, and tests guard every
		allocation count.
	</Card>
	<Card title="One write per record" icon="list-format">
		Each line is one `Write` under a lock shared by every handler made from it, so lines from many goroutines never mix.
	</Card>
	<Card title="Small API" icon="puzzle">
		One constructor, four options and a `CRITICAL` level. No dependencies beyond the standard library.
	</Card>
</CardGrid>

## Less work per record than slog's own handlers

<div class="landing-lead">
	golog writes fewer bytes than slog.TextHandler, quotes without going rune by rune, and formats the time in full
	once a second. Against v1, it allocates nothing and drops a record below the level before formatting it.
	With 16 goroutines at once, the time is wall time per record across all of them, so it measures throughput.
</div>

## Coming from v1

<div class="landing-lead">
	v2 is a handler for log/slog instead of a logger of its own. The calls become slog's, the values become
	attributes, and the levels keep their names.
</div>

<div class="compare">

```go title="v1"
logger := golog.New()

logger.Info(ctx, fmt.Sprintf(
	"user %s signed in from %s",
	name, ip,
))
logger.Critical(ctx, "disk full")
```

```go title="v2"
logger := slog.New(golog.NewHandler(
	os.Stdout, &golog.Options{Color: true},
))
logger.InfoContext(ctx, "user signed in",
	"user", name, "ip", ip)
logger.Log(ctx, golog.LevelCritical,
	"disk full")
```
